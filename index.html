Run Hello World on your Mac or Linux computer +
  1. Clone the repository and open its folder:
    git clone https://github.com/LucasLi1337Unknown/EMMcry.git
cd EMMcry
  2. Install the compiler dependency:
    python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
    If your Mac does not have c++, run xcode-select --install first.
  3. Save ...! "Hello, World!" in hello.emm.
  4. Compile and run:
    python3 emmc.py hello.emm -o hello
./hello
  5. Translate it into the emoji language:
    python3 emmc.py --translate hello.emm hello.cry
python3 emmc.py hello.cry -o hello-cry
./hello-cry

    03 / UNDER THE HOOD

    A joke with an engine.

    EMM and 😭 are two ways to write the same program. The compiler parses either into a shared representation. That can become a native executable, or run in the browser VM used by this arcade.

    The JavaScript interface draws the board and passes your actions in. The EMM files decide what happens: enemies move, tiles merge, hands are scored. You can inspect every rule.
